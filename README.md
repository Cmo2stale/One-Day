# One Day Daily

A free daily companion for people in recovery: a morning message, a private journal (speak or type), daily check-ins with an evening review, progress and milestones, and an "I'm struggling" screen for hard moments.

Everything a person writes is saved only on their own phone or computer. If someone turns on the optional AI responses, journal text is sent through the app's server to an AI service to write a reply, and isn't stored there. See privacy.html.
